# Функции и методы

Сигнатуры и назначение функций реализации.


## __init__.py

| Функция | Назначение |
| --- | --- |

## __main__.py

| Функция | Назначение |
| --- | --- |
| `execute(config, stage)` | Выполнить выбранный этап; по умолчанию вывести PlantUML. |
| `main()` | Разобрать аргументы и преобразовать ошибки в код завершения 2. |

## config.py

| Функция | Назначение |
| --- | --- |
| `Config.items(self)` | Вернуть параметры для демонстрации первого этапа. |
| `load_config(path)` | Загрузить строгую схему TOML; сообщить об ошибке параметра. |
| `validate_fields(data)` | Проверить типы, имена пакетов, версию и глубину. |

## graph.py

| Функция | Назначение |
| --- | --- |
| `build_graph(repository, root, max_depth)` | Обойти зависимости BFS без рекурсии; корень имеет глубину ноль. |
| `dependency_order(graph)` | Получить порядок «зависимости раньше потребителей» без рекурсии. |
| `truncated_nodes(graph, max_depth)` | Найти граничные вершины с нераскрытыми положительными связями. |

## plantuml.py

| Функция | Назначение |
| --- | --- |
| `to_plantuml(graph, max_depth)` | Сформировать диаграмму; стрелка направлена к зависимости. |

## repository.py

| Функция | Назначение |
| --- | --- |
| `Package.key(self)` | Версия является частью идентификатора вершины. |
| `parse_dependency(text)` | Разобрать имя и необязательное ограничение версии. |
| `Repository.__init__(self, packages)` | Индексировать записи, сохраняя версии виртуальных provides. |
| `Repository.resolve(self, dependency)` | Выбрать новейшего подходящего поставщика; иначе выдать ошибку. |
| `Repository.root(self, name, version)` | Найти именно указанную версию реального корневого пакета. |
| `parse_index(text)` | Прочитать P, V, D, p из текстового APKINDEX без сторонних средств. |
| `read_remote(url)` | Скачать APKINDEX.tar.gz и прочитать его без распаковки на диск. |
| `read_test(path)` | Прочитать JSON-граф с именами из больших латинских букв. |
| `validate_test_record(name, record)` | Проверить формат версии и зависимостей тестового пакета. |
| `load_repository(config)` | Выбрать источник данных согласно TOML. |

## versions.py

| Функция | Назначение |
| --- | --- |
| `tokens(version)` | Разбить версию на числовые, буквенные и служебные компоненты. |
| `compare(left, right, fuzzy=False)` | Вернуть -1, 0, 1; fuzzy сравнивает префикс компонентов. |
| `satisfies(actual, operator, expected)` | Проверить ограничение зависимости, включая совместимый префикс ~. |
